安装步骤

  1. 确保已安装 Java 11 或更高版本（JDK/JRE 均可，安装程序与主程序都依赖它）。
  2. 下载 FireToolboxInstaller.jar。
  3. 双击该 jar，弹出安装向导；选择安装目录（默认 %LOCALAPPDATA%\\FireToolbox）。
  4. 点击「安装」，等待进度条完成。安装程序会自动释放主程序文件并生成 启动.bat。
  5. 勾选「创建桌面快捷方式」后，桌面会出现「Fire工具箱」；勾选「安装完成后启动」可立即打开。

运行要求

  1. 操作系统：Windows 10/11（其他系统需手动运行 jar）。
  2. Java：11 或更高版本，需能从命令行调用 java。
  3. 磁盘：安装目录约需 20 MB（含内置资源与语言包）。
  4. 若双击 jar 无反应，请检查 .jar 是否关联到 javaw.exe（见下方常见问题）。

常见问题

双击 jar 没有反应？

通常是 .jar 没有关联到 Java。右键 jar →「打开方式」→ 选择 JDK/JRE 目录下的 javaw.exe， 勾选「始终使用此应用打开 .jar 文件」。

安装后启动崩溃？

检查安装目录下是否有 Config.ini。程序要求 Config.ini 存在，缺失会主动崩溃并写入 resources/log/crash.log。

如何切换语言？

打开程序 →「设置」→ 语言，可选简体中文、繁体中文、英文、俄语。切换后点「保存」写入 Config.ini。

如何卸载？

直接删除安装目录，并删除桌面「Fire工具箱」快捷方式即可。程序不在系统其他位置写入文件。
